## 7. 測定手法として蓄積されたもの

- **陽性コントロールを両方向で取る**。「0件」は「検出器が黙っている」かもしれない。
  `am crash` で14行拾えることを確認してから「crash 0件」と言う
- **壊れた版を実際にビルドして測る**。Q2 は修正を外した APK を install して
  「入力欄が永久に disabled」を再現してから、修正版で復帰することを測った
- **計器そのものを校正する**。Q7 の `diff-hscroll` は5条件で全部違う値を返すことを確認した
  (定数を返す偽計器ではない)
- **`content-desc` は押せるノードに付ける**。付いていないと dump は押せない子ノードの寸法を返す

  **44.4dp × 48dp(左端11pxが死ぬ)**を測った。原因は未特定
- **`uiautomator dump` の `text` にはスクロール前から内容全体が入る**。
  「末尾の文字列が出た」はスクロール到達の証拠にならない
- **`uiautomator dump` の bounds は横スクロールで動かない**(クリップ矩形)
- **横スワイプはエッジ帯(x<60 / x>1020)を避ける**。ジェスチャーナビの「戻る」が発動して
  アプリがホームへ落ちる(Q7 の E2E が踏んだ)
- **`am start` でプロセスが立て直ると VM が新品になる**。`mCurrentFocus` を確認すること
- **`test-results` を消さないと Gradle が `UP-TO-DATE` でタスクごと飛ばす**(Q8)
